# Post-freeze changes

Record every change made after `results/freeze/freeze_record.json` was first written. Changes to the frozen configuration block, to result-relevant code, or to the code cells of the analysis notebooks (02, 05 to 09) stop notebooks 06 to 10 until the run is repeated with `MBSHEDGE_ALLOW_POST_FREEZE=1`. Every evaluation after such a change is marked `post_freeze` in `results/freeze/test_evaluation_log.csv`.
